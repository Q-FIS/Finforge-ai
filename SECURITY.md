# Security Policy

## Supported Versions

FinForge AI is currently in active pre-alpha development (`0.1.0.dev0`). We provide security updates and patches for the current development line on `main`.

| Version     | Supported          |
| ----------- | ------------------ |
| 0.1.x (dev) | :white_check_mark: |
| < 0.1       | :x:                |

## Reporting a Vulnerability

We take the security of FinForge AI and its ecosystem seriously. If you believe you have discovered a security vulnerability, please do **NOT** open a public issue.

Instead, please report security vulnerabilities responsibly using one of the following methods:

1. **GitHub Security Advisory**: Navigate to the [Security Advisories](https://github.com/finforge-ai/finforge-ai/security/advisories) tab on GitHub and click "Report a vulnerability".
2. **Private Security Report**: If GitHub Security Advisories are unavailable, submit a confidential report to the project maintainers via the designated security contact point.

### What to Include

To help us triage and resolve the vulnerability effectively, please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (including minimal proof-of-concept scripts or configuration files).
- The operating system, Python version, and dependency versions used.
- Any potential remediations or patches you have identified.

### Disclosure Process

1. **Acknowledgement**: The maintainers will acknowledge receipt of your report within 48 hours.
2. **Investigation**: We will investigate and confirm the vulnerability in an isolated environment.
3. **Remediation**: A fix will be developed in a private branch.
4. **Advisory & Release**: A coordinated security advisory and patched release will be published simultaneously, crediting the reporter if desired.
